# Cuestionario y criterios aprobados

Fuente: aclaraciones del organizador recibidas el 3 de noviembre de 2026. No ampliar ni alterar estas reglas sin nueva aprobación.

## FINDRISC

Ocho factores puntuados:

- Edad: <45 = 0; 45–54 = 2; 55–64 = 3; >64 = 4.
- IMC: <25 = 0; 25–29,9 = 1; ≥30 = 3. Calcular peso/altura² y redondear a un decimal antes de asignar tramo.
- Cintura hombres: <94 = 0; 94–102 = 3; >102 = 4 cm.
- Cintura mujeres: <80 = 0; 80–88 = 3; >88 = 4 cm.
- Actividad: Sí (≥30 min diarios) = 0; No = 2.
- Frutas/verduras a diario: Sí = 0; No = 1.
- Medicación antihipertensiva: Sí = 2; No = 0. Se mapea únicamente «Sí, con medicación» a Sí.
- Hiperglucemia previa: Sí = 5; No = 0.
- Familiares: ninguno = 0; abuelos/tíos/primos = 3; padres/hermanos/hijos = 5.

Interpretación total: <7 bajo; 7–11 ligeramente aumentado; 12–14 moderado; 15–20 alto; >20 muy alto. Si diabetes actual=Sí, no calcular; mostrar «No aplicable: paciente con diabetes actual». Registrar respuestas. MEDAS se calcula normalmente.

## MEDAS

Cada uno de los 14 criterios suma 1 si cumple: aceite de oliva principal; ≥4 cucharadas/día; ≥2 raciones verduras/día; ≥3 frutas/día; <1 ración diaria carnes rojas/embutidos; <1 ración diaria mantequilla/margarina/nata; <1 bebida azucarada/día; ≥7 vasos de vino/semana; ≥3 raciones de legumbres/semana; ≥3 raciones de pescado/marisco/semana; repostería comercial no casera <3 veces/semana; ≥3 raciones frutos secos/semana; preferencia por carne blanca; sofrito ≥2 veces/semana. Total 0–14.

Interpretación aprobada: <9 baja adherencia; ≥9 buena adherencia.

## Campos y preguntas

Actividad física sustituye la pregunta 14 original con la redacción: «¿Realiza habitualmente al menos 30 minutos diarios de actividad física, en el trabajo y/o en el tiempo libre (incluida la actividad diaria normal)?» Opciones Sí/No.

Repostería comercial: «Menos de 3 a la semana» (1 punto) / «3 o más a la semana» (0 puntos).

Añadir Sexo obligatorio: Hombre/Mujer (sexo biológico para umbrales cintura). TSI obligatorio, textual, inicial `001`–`006`, ampliable desde panel.
